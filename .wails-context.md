# 🚀 Kube Simulator - Architecture & Context Map

This document provides a concise, developer and AI-friendly context map of the Kube Simulator codebase. Use this guide to quickly understand the project structure, state management, simulation engine, and integration patterns.

---

## 📂 Codebase Structure Map

```
├── backend/
│   ├── db/                 # Persistent SQLite settings, badger-based history manager (undo/redo).
│   ├── k8s/                # Core Kubernetes resource Go types and models.
│   ├── logger/             # Custom Wails-compatible Go logger.
│   ├── system/             # System resource monitoring metrics (CPU/Mem) and updates.
│   └── yaml_gen/           # Pure-Go generator producing multi-resource Kubernetes YAML manifests.
├── frontend/
│   ├── src/
│   │   ├── components/     # UI components: Layout, Nodes (React Flow), Config, Monitoring, Modals.
│   │   ├── constants/      # Predefined configurations, connection validation matrices.
│   │   ├── hooks/          # React hooks for drop-handling, shortcuts, and auto-zoom.
│   │   ├── lib/            # Utilities, logging system, shepherd.js tour, and simulation engine.

└── app.go                  # Main Wails App entrypoint binding backend Go methods to the frontend.
```

## ⚡ State Management (Zustand & Slices)

The frontend uses **Zustand** as its single source of truth (`frontend/src/store/useFlowStore.ts`). It is composed of modular slices to maintain high readability and low cognitive complexity:

1. **`createFlowSlice`**: Manages nodes, edges, connections, reconnecting, and automatic canvas layout (powered by Dagre).
2. **`createDeploymentSlice`**: Manages deployment-specific configurations and container sync layouts.
3. **`createNodeSlice`**: Manages standalone node configurations (such as standard Pods, Services, PVCs).
4. **`createUiSlice`**: Controls UI toggles, panels, settings, and start/stop simulation states.
5. **`createLogSlice`**: Centralized console and backend event logging.

### 🔄 Undo & Redo Integration
Every state change that updates `lastActionId` is automatically serialized as a JSON snapshot and pushed to the Go-based BadgerDB history manager (`App.PushHistory`). When Undo/Redo is triggered, the state is retrieved from the database and reapplied to the store using `applyHistoryState`.

## 🛠️ Canvas Engine (React Flow) & Node Hierarchy

Kube Simulator models Kubernetes resources visually as custom React Flow nodes:
- **Namespaces**: Act as bounding container boxes for other nodes.
- **Workloads (Deployments / Pods)**: Contain dynamic pod configurations. Pods within Deployments are synchronized in count and laid out dynamically based on the replica count threshold.
- **Connections & Handles**: Calculated dynamically during drag/drop using `optimizeEdgeHandles` to select the shortest visual path from 16 handle pairs. Reconnections are limited to the Target handle (`reconnectable: 'target'`).

## 📊 The Simulation Engine (`frontend/src/lib/simulation.ts`)

The active simulation updates cluster states on each "tick":
1. **PVC Readiness**: Pods remain in `pending` state if their referenced `PVC` node is not yet `Bound`.
2. **Traffic & Routing**: Active edges route mock traffic originating from `Internet` nodes through `Ingress` -> `Service` -> `Workload`.
3. **Resource Metrics**: Computes virtual CPU/Memory loads dynamically.
4. **Hysteresis / OOM Crashes**: High memory usage triggers Out-Of-Memory (OOM) pod crashes. Crashing pods are removed and rescheduled using a Go-compatible mock timer.
5. **HPA Autoscaling**: Horizontal Pod Autoscalers dynamically increase/decrease parent deployment replicas based on virtual CPU utilization.

## 📡 Wails Bridge & Go Backend Binds

Communication between the React frontend and Go backend occurs via standard Wails bindings, imported using `@wailsjs/runtime` or `wailsjs/go/main/App`:
- `GenerateYaml(nodes, edges)`: Offloads visual-to-YAML translation to Go's robust manifest builder.
- `GetSystemResources()`: Pulls host CPU/Memory metrics safely (using OS-specific scripts).
- `SaveSetting(key, val) / GetSetting(key)`: Manages persistent JSON settings (`app_settings_json`) inside SQLite.

## 📐 AI & Code Quality Guidelines

- **Cognitive Complexity**: All functions, methods, handlers, and React components must strictly observe a maximum **Cognitive Complexity limit of 15** (in accordance with SonarQube static analysis standards). Helper methods and sub-handlers must be modularized into helper files or top-level functions whenever complexity approaches this limit.
- **React Component Keys**: Do not use raw Array index in keys (e.g. `key={index}`). Always use unique string IDs or composite keys (e.g., `key={`part-${part}-${index}`}`) to comply with SonarQube static analysis rules and prevent React rendering bugs.
